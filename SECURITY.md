# Security policy

## Reporting a vulnerability

Please report suspected security issues in privify.io or this repository to **security@privify.io**.

- Include the affected URL or file, what you observed, and steps to reproduce.
- Please do not publicly disclose the issue until we have had a reasonable chance to fix it.
- Do not access, modify, or retain data that is not yours, and do not run denial-of-service tests.

We aim to acknowledge reports within 3 business days.

## Scope

This repository is a static marketing site served by GitHub Pages. It holds no customer data and no credentials.
Issues in Privify's products should also be sent to the address above.
